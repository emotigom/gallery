# AI 개인 작품 갤러리

중학생 창작 수업에서 만든 AI 음악·만화·그림책을 한 페이지에 전시하는 정적 웹 갤러리입니다. 별도의 빌드 과정 없이 HTML, CSS, JavaScript만으로 실행됩니다.

## 주요 기능

- 작품별 카드형 소개
- 음악 재생과 중복 재생 방지
- 만화 슬라이드 탐색
- 모바일 화면 대응

## 실행

```bash
cd gall
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.
